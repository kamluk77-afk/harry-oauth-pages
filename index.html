Harry Backup Production

Harry Backup Production is a personal backup utility used to store and recover encrypted backups in the owner's Google Drive account.

How it works

The application uses Google Drive access to create and manage backup files. Backup data is encrypted locally using Restic before upload.

Google Drive permissions

The application requests access to files created or managed through the application using the Google Drive drive.file permission.
